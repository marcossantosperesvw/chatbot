# Windows: localizar versão e especificações básicas do computador

Status: rascunho geral, não indexado; revisão humana pendente.

Fonte: [Microsoft — Encontrar informações sobre seu dispositivo Windows](https://support.microsoft.com/pt-br/windows/experience/find-information-about-your-windows-device).

Consulta documental: 2026-10-19. Resumo; procedimento não executado.

## Escopo

Consulta de informações no Windows. Interface não validada em um dispositivo real.

## Procedimento

1. Abra Configurações > Sistema > Sobre.
2. Consulte processador, RAM instalada e tipo de sistema em Especificações do dispositivo.
3. Consulte edição e versão em Especificações do Windows.
4. Para espaço disponível, abra Configurações > Sistema > Armazenamento.

## Limites e cuidados

Esses dados ajudam a descrever o computador, mas não comprovam compatibilidade
ou desempenho de um jogo. Este procedimento não identifica todos os componentes
necessários para essa análise, como a placa de vídeo.

Recomendação editorial de privacidade: compartilhe apenas os dados técnicos
necessários, sem identificadores do dispositivo, chaves de produto ou dados da conta.

## Perguntas de avaliação

- Onde encontro minha versão do Windows e a RAM?
- Onde vejo espaço disponível?
- Só informar a RAM comprova que um jogo funciona? Não comprova.
- Posso enviar uma captura inteira? Preferir dados necessários, sem identificadores.
