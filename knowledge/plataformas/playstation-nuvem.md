# PlayStation Plus: diferenças entre saves PS4 e PS5 na nuvem

O armazenamento em nuvem de dados salvos exige assinatura PlayStation Plus.
No console PS5, jogos de PS5 podem sincronizar automaticamente os dados recentes
entre console e nuvem. Para jogos de PS4, o upload pode ser automático, mas o
download dos saves para o PS5 precisa ser feito manualmente.

Em Configurações > Dados salvos e configurações de jogos/aplicativos, selecione
Dados salvos (PS5) ou Dados salvos (PS4). Para PS5, procure Sincronizar dados salvos;
para PS4, Upload automático. A sincronização depende das configurações exigidas,
incluindo atualizações automáticas e conexão à internet no modo de repouso.

Para conferir um jogo de PS5, destaque-o na tela inicial, pressione Opções e
consulte o status de sincronização dos dados salvos. É possível controlar a
sincronização por jogo. Para recuperar dados de PS4, use a opção de download
do armazenamento em nuvem na categoria correspondente.

Esse recurso transporta saves; não comprova que uma versão PS5 importa um save
da versão PS4. Este guia não determina qual cópia deve substituir outra.
